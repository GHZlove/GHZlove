## Featured Projects

### Number Extraction

A modular HTML5 Canvas game prototype combining equal-number merging, tactical combat, exploration and extraction.

- Separates simulation, rendering, input, UI and storage across 10 JavaScript modules.
- Uses a fixed simulation step, collision detection, line-of-sight checks and seeded map generation.
- Includes persistent base upgrades and settlement rules that prevent duplicate rewards within the current session.
- Has 19 automated tests covering gameplay rules, an extraction-to-upgrade cycle, save handling and sampled map reachability.

**Status:** Private v0.1 prototype. Public showcase planned after documentation and playtesting review.

### Cloud Hop

A browser platform-jumping prototype with charge-and-release controls, a separate physics module, scoring and restart logic.

**Technical focus:** Input handling, game physics and interaction testing.

**Status:** Private prototype. Further browser and touch-device validation is planned.
